# Documentation Map

## Implementation docs
Implementation and runtime architecture docs live under `backend/docs/`.

## Product and vision docs
Product, enterprise, GTM, and whitepaper docs live under `docs/`.

## Authoritative locations
- backend runtime and subsystem behavior: `backend/docs/`
- product positioning and market narrative: `docs/`

## Roadmap authorities

- active Customer UX and Growth execution:
  `docs/claude-next-build-brief.md`
- detailed UX recovery history and UX1-UX9 checklist:
  `docs/ui-ux-productization-plan.md`
- Supabase/Vercel deployment, security, and release gates PR0-PR6:
  `docs/production-readiness-roadmap.md`
- historical platform-foundation sequence P1-P10:
  `docs/product_overview/sprint_roadmap.md`

Sprint numbers must include their track prefix (`P`, `UX`, `PR`, or `G`) in new
issues and status reports.
